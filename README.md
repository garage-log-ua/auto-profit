# Складський облік (PWA)

Простий складський облік з приходом, продажами, комплектами, відправками та спільною синхронізацією через Firebase.

## Файли

- `index.html` — основний додаток
- `manifest.json` — маніфест PWA
- `sw.js` — service worker
- `icon-192.png` / `icon-512.png` — іконки

## Публікація

1. Створи репозиторій на GitHub.
2. Завантаж ці файли в корінь репозиторію.
3. Увімкни GitHub Pages (Settings → Pages → Deploy from branch → main / root).
4. Відкрий отримане посилання.

Дані зберігаються в Firebase Realtime Database (налаштовано в `index.html`).
